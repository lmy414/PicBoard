# PicBoard

Windows 本地优先的剪贴板增强工具。

复制过的文字、富文本、链接和图片，PicBoard 会在后台记进“剪贴板历史”。想留下的内容拖到无限画布上整理，需要时双击打开编辑或查看，再复制出去用。

不需要账号、服务器或云同步。内容默认保存在本机。

## PicBoard 能帮你做什么

- 后台记录复制过的内容，不用先打开软件。
- 把想留的内容拖到无限画布上，按主题分画布、分子画布整理。
- 双击内容打开整页：文本进入所见即所得编辑器，图片看大图，链接打开详情页。
- 从节点边缘拖出连线，标出内容之间的关联。
- 同一条内容可以放在多个画布上，改一处各处同步。
- 文本里可以直接插图：粘贴图片，或输入 `/` 选择“图片”。
- 画布网格和背景都能在设置里调整。
- 按类型、分类、创建时间筛选和搜索，按原格式复制出去。
- 历史保留时间可调，没放到画布、也没分类的旧内容会自动清理。

## 快速开始

1. 下载并解压 Windows x64 便携包。
2. 运行 `PicBoard.exe`：主窗口打开，系统托盘里出现图标。
3. 正常复制文字、链接或图片，右侧“剪贴板历史”会自动出现记录。
4. 把历史里的内容拖到画布上，或在画布中按 `Ctrl+V`。
5. 双击画布上的内容，打开整页查看或编辑。

## 主要交互

菜单、对话框、提示条、整页、历史条目、分类库卡片、节点和连线在出现和消失时都有缓动动画。系统的“减少动态效果”开启后，这些动画会关闭。

### 主窗口

| 操作 | 结果 |
| --- | --- |
| 拖动标题栏 | 移动窗口 |
| 双击标题栏，或点击“□” | 最大化或还原 |
| 点击“−” | 最小化到任务栏 |
| 点击“×” | 按设置处理：默认收纳到托盘，进程和后台记录继续；可在设置的“窗口与启动”里改为退出程序 |
| 拖动窗口边缘 | 自由调整大小，最小 720×480；大小和位置会记住 |

窗口默认 1000×700。宽度 ≥1100 px 时侧栏靠边显示，更窄时侧栏收成细栏、点开是浮层；历史面板在画布足够宽时靠边，否则改为浮层；窗口宽度 ≤900 px 时，设置、历史和画布工具按钮收进顶部栏的“⋯”菜单；画布太窄时小地图自动隐藏。

### 托盘

| 操作 | 结果 |
| --- | --- |
| 左键点击托盘图标 | 打开或收起剪贴板面板 |
| 右键点击托盘图标 | 打开 PicBoard / 退出 |
| 面板失去焦点 | 自动收起 |

剪贴板面板约 420×600，出现在托盘图标旁边：

| 操作 | 结果 |
| --- | --- |
| 点击“记录中”或“已暂停” | 暂停或恢复后台记录 |
| 点击“打开主窗口”或“设置” | 打开主窗口；设置按钮直接进设置页 |
| 类型标签 | 全部、文本、图片、链接，带数量；文本标签同时覆盖富文本 |
| 搜索框 | 按内容文字、链接、文件名搜索；直接打字会聚焦到这里 |
| “今天 N 条 · 共 M 条” | 当天和总的记录数 |
| 单击条目 | 按原格式复制 |
| `Space`，或点击条目上的箭头 | 展开或收起预览 |
| 双击条目 | 在主窗口打开这条内容 |
| “⋯”或右键条目 | 复制、预览、在主窗口打开、分类（可新建）、删除内容（行内确认） |
| `↑` / `↓` / `Enter` / `Delete` | 选择上一条或下一条 / 复制选中项 / 删除确认 |
| `Esc` | 逐层关闭：菜单 → 删除确认 → 预览 → 收起面板 |
| 底部“打开 PicBoard”“退出” | 打开主窗口 / 结束进程 |

列表按时间倒序，滑到底部继续加载。开启“开机自启动”后，PicBoard 静默进入托盘，不弹主窗口。

### 剪贴板历史（主窗口）

| 操作 | 结果 |
| --- | --- |
| 复制内容 | 记录开启时，自动出现在右侧历史 |
| 点击“记录中”或“已暂停” | 暂停或恢复后台记录，已有历史不受影响 |
| 双击条目或按 `Enter` | 打开整页 |
| 按住条目拖到画布 | 放到松手的位置 |
| 右键条目 | 打开操作菜单：打开、复制、分类、重命名（图片）、删除内容 |
| 搜索框 | 按内容文字、链接、文件名搜索 |
| 类型按钮 | 只看文本、富文本、链接或图片 |
| 滚动到底部 | 继续加载更多历史 |

暂停记录后，新复制的内容不再进入历史。暂停按钮在历史面板顶部，设置页的“剪贴板”一节也有同一个开关。

### 画布与层级

| 操作 | 结果 |
| --- | --- |
| 中键拖动，或按住 `Space` 后左键拖动 | 平移画布 |
| 滚轮 | 以指针位置为中心缩放，范围 50%–150% |
| 在空白处拖动 | 框选节点 |
| 点击“定位全部” | 把当前画布的内容移进视野 |
| 左侧树顶部的“＋” | 新建根画布 |
| 点击左侧树节点 | 切换到该画布 |
| 树节点上的“＋”，或右键“新建子画布” | 在该画布下新建子画布 |
| 在树中拖动节点 | 调整父子层级或顺序；拖动时底部出现“拖到此处设为根画布”，放上去变回根画布 |
| 双击子画布卡片 | 进入该子画布，子画布可以无限嵌套 |
| 拖动子画布卡片 | 调整卡片在父画布上的位置 |
| 把节点拖到子画布卡片上 | 移入该子画布 |
| 右键子画布卡片 | 进入、重命名、解组、删除 |
| 点击面包屑或按 `Esc` | 返回上一级画布 |
| 点击画布工具里的“网格对齐” | 开关拖动吸附；按住 `Alt` 拖动可临时反转当前模式 |
| 设置 → 画布 | 图案（网点、网格线、无）、背景颜色、图案颜色与浓度、网格间距 16/24/32、网格对齐 |

点击顶部“⋯”可以展开或收起画布工具，里面有网格对齐、缩放、定位全部和历史开关。默认是暖白背景加网点，间距 24，网格对齐关闭（自由移动）。图案跟随画布的平移和缩放一起移动。

### 节点与连线

| 操作 | 结果 |
| --- | --- |
| 单击节点 | 选中 |
| `Shift` + 单击 | 增选或取消选择 |
| 拖动节点或子画布卡片 | 直接跟随指针，自由移动时与指针完全同步；开启网格对齐后按网格步进；按下时轻微放大抬起，松开后缓动落位 |
| 双击节点或按 `Enter` | 打开整页 |
| 从节点边缘的连接点拖到另一个节点 | 建立连线，箭头指向目标节点 |
| 点击连线 | 选中连线 |
| `Delete` / `Backspace` | 删除选中的节点或连线 |
| 右键节点 | 打开操作菜单：打开、复制、分类、重命名（图片）、创建子画布、从画布移除、删除内容 |
| 右键连线 | 删除连线 |

连线只表示关联，不传递数据。删除节点时，连到它的连线一起删除。一端被收进子画布后，连线画在子画布卡片上；解组后连线回到原来的节点。

节点和子画布卡片之间始终保留 16 px 间距，不会重叠。拖到或粘贴到已占用的位置时，内容会自动滑到最近的空位；文本变高后，被挡住的内容向下让位。

### 整页查看与编辑

| 内容类型 | 打开后 |
| --- | --- |
| 文本、富文本 | 所见即所得编辑器。输入 `/` 插入标题、列表、待办、引用、代码块、分割线、表格和图片；选中文字出现格式工具条；停止输入约 0.6 秒自动保存 |
| 图片 | 大图查看。滚轮缩放，拖动平移，双击在适应窗口和 100% 之间切换 |
| 链接 | 显示地址，可以改地址、复制链接，或在浏览器打开；只允许 http/https 地址，不会抓取网页内容 |
| 子画布 | 直接进入该子画布 |

文本页可以直接插图：粘贴图片文件、粘贴带图片的 HTML，或输入 `/` 选择“图片”。图片保存在这条内容自己的目录里，远程图片不会加载。画布卡片、历史列表和分类库会用第一张图作为封面；纯文本里图片显示为 `[图片]`；复制富文本时，图片以内嵌形式写入 HTML（单张 8 MB、合计 24 MB 以内）。

整页顶部显示内容类型、分类和创建/编辑时间，文本页还会显示保存状态。页面同时列出这条内容出现在哪几个画布，点击画布名可以直接跳过去。按 `Esc` 或点页面左上角的“← 返回”回到原位置，顶部栏的来源面包屑也可以点击返回。有弹窗或菜单时，`Esc` 先关闭它们，再关闭整页。

### 分类库

| 操作 | 结果 |
| --- | --- |
| 单击卡片 | 选中；`Shift` + 单击多选 |
| 双击卡片或按 `Enter` | 打开整页 |
| 顶部类型按钮 | 只看某一类型，“全部”后面是总数 |
| 分类下拉 | 按分类筛选，包含“未分类” |
| 时间下拉 | 全部时间、今天、7 天内、30 天内 |
| 搜索框 | 按内容文字、链接、文件名搜索 |
| 右键卡片，或点击选中后出现的“操作” | 打开、复制、分类、重命名（图片）、删除内容 |
| `Ctrl+C` | 复制选中的内容 |

分类只是标记，不会移动文件。文本、富文本、链接和图片都可以分类。

### 设置与外观

设置页第一节“外观”提供两种界面主题：

| 主题 | 样子 |
| --- | --- |
| 简洁（默认） | 平面浅色界面，细边框与轻阴影，适合长时间浏览 |
| 新拟物 | 柔和的凹凸光影，控件像从底色中浮出 |

切换后立即生效，主窗口和托盘面板一起换，重新启动后保持。切换时有一次短的交叉淡入；系统的“减少动态效果”开启时直接切换。画布背景没有自定义过时跟随主题，改过之后以自定义颜色为准。

### 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+C` | 复制画布上选中的节点，或分类库中选中的内容 |
| `Ctrl+V` | 把剪贴板内容粘贴到当前画布 |
| `Ctrl+K` | 把焦点移到左侧画布搜索框 |
| `Delete` / `Backspace` | 删除选中的节点或连线 |
| `Shift` + 单击 | 增选或取消选择 |
| `Enter` | 打开选中的节点、历史条目或分类库卡片 |
| `Esc` | 取消选择；没有选择时返回上一级画布；整页中先关闭弹窗或菜单，再返回 |
| `Space` + 拖动 | 平移画布 |
| 编辑器内 `Ctrl+B` / `Ctrl+I` / `Ctrl+U` | 加粗、斜体、下划线 |

### 处理节点插件（仅接口）

这个版本只提供插件接口。设置页的“插件（处理节点接口预览）”会列出插件目录里的插件、加载状态和它们声明的输入输出，还不能在画布上运行处理节点。

插件格式、清单字段、端口类型和运行契约见 [docs/PLUGIN-API.md](docs/PLUGIN-API.md)。

## 数据与隐私

PicBoard 是本地优先应用：

- 不需要账号，不上传内容，应用本身不联网。
- 记录开启时，PicBoard 在后台读取 Windows 剪贴板，把复制过的内容存到本机。
- 可以随时暂停记录。暂停后不再新增记录，已有历史保留。
- 遵守 Windows 的剪贴板排除标记。来源应用设置了 `ExcludeClipboardContentFromMonitorProcessing`、`CanIncludeInClipboardHistory = 0` 或 `Clipboard Viewer Ignore` 时，内容不会记录。密码管理器通常会用这些标记。
- PicBoard 自己复制出去的内容带标记，不会被再次记录。
- 历史保留时间默认 30 天，可以改为 7 天、30 天、90 天、1 年或永久保留。自动清理只删除既没有放到画布、也没有分类的内容，并且直接删除对应文件，不进回收站。

默认数据目录为：

```text
%APPDATA%\quick-image-board\quick-image-board
```

目录内容：

```text
state.json             业务状态（schema v2）
state.json.bak         上一次写入成功的状态
state.v1-backup.json   从 v1 升级时保留的原始状态
desktop-settings.json  关闭行为、自启动、记录开关、历史保留、网格间距与对齐、窗口大小与位置
content\<id>\…         文本、富文本 HTML 和图片文件
content\<id>\assets\…  富文本里插入的图片
cache\thumbs\…         缩略图缓存，可以删除，会重新生成
plugins\<文件夹>\…     处理节点插件
pending\、classified\  旧版本遗留的文件位置，不会移动
```

升级说明：这个版本第一次启动时会把旧的 `state.json`（schema v1）升级为 v2，并把原文件保留为 `state.v1-backup.json`。v0.1.2 的旧版本读不了升级后的数据，所以要用新版本处理真实数据前，先备份整个数据目录。

重要内容仍建议自行备份。设置中的路径偏好不会自动搬运已有文件。

## 开发与构建

### 开发环境

- Windows 10/11 x64
- Node.js 21 或更高版本（测试脚本使用 `node --test` 的通配符）
- Rust 1.77.2 或更高版本
- Microsoft Edge WebView2 Evergreen Runtime

安装依赖：

```powershell
npm install
```

### 启动开发版本

Rust/Tauri 是当前唯一的桌面开发入口：

```powershell
npm run dev
```

开发启动默认使用独立的临时数据目录，不会触碰正式用户内容和设置。需要使用指定测试数据目录时，可以显式传入：

```powershell
npm run dev:rust -- --data-root "C:\path\to\picboard-test-data"
```

只调试前端渲染器时，也可以启动 Vite：

```powershell
npm run dev:renderer
```

### 检查与测试

```powershell
npm run typecheck
npm test
npm run build
cargo check --manifest-path src-tauri/Cargo.toml
```

`npm test` 依次运行三组测试：

- `node --test tests/*.test.mjs`：Node 测试。
- `vitest run`：匹配 `tests/**/*.test.{ts,tsx}` 的组件与逻辑测试。
- `cargo test --manifest-path src-tauri/Cargo.toml --lib`：Rust 测试。

新增的 `.test.mjs` 和 `.test.ts(x)` 文件会被自动收进对应测试，不需要改 `package.json`。

### 构建 Windows x64 便携版

在项目根目录执行：

```powershell
powershell -NoProfile -File scripts/package-portable.ps1
```

构建结果位于 `release/`，包括 Windows x64 便携 ZIP 和对应的校验清单。打包脚本会构建 Tauri/Rust 发布版本、收集第三方许可文件。发布包使用系统 WebView2，不包含固定版 WebView2，也不是签名安装器。

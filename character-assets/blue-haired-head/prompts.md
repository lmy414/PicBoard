# Draft layer prompt set

These are the image-tool requests used to make the current sample. The base, hair, eyes, and mouths were generated as separate transparent images using the original attachment as identity reference. They are reconstructions, not pixel-exact source extractions.

- **Head base:** isolated rounded pale face/head, source-matched line and shading, cheeks retained, no hair/eyes/mouth, centered transparent canvas.
- **Back hair:** dense blue/cyan/navy hair cap behind the face, transparent central opening sized for the face, no skin or face features.
- **Front hair candidate:** short bangs only, transparent eye and mouth regions. The model did not respect the eye-clear area in its current output, so that layer is retained for review and excluded from previews.
- **Eyes:** source-matched dark oval pair with small highlights on the face eye line, all other pixels transparent.
- **Mouths:** separate neutral closed mouth and open intake mouth on the same center anchor.

The exact reusable prompt pattern is in `skills/anime-orb-character/references/layer-prompts.md`.

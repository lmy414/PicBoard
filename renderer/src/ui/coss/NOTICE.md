# coss ui

`Primitives.tsx`, `../Select.tsx`, and the settings slider adapt components from
the coss ui registry at `cosscom/ui@b2336c45f2b7355c42678ce786b6f14d62b819be`
(`apps/ui/registry/default/ui`). The components use Base UI and the PicBoard
theme, layout, and desktop focus conventions. See `LICENSE` for the upstream
MIT license.

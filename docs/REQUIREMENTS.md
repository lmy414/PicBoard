# 快捷图片画布：第一阶段需求

## 1. 产品定位

一个本地优先的桌面悬浮窗图片管理工具。用户可以把聊天中的图片快速放入临时画布，稍后再选择分类归档，也可以将图片文件快速拖出或复制到剪贴板。

## 2. 第一阶段范围

- 只做本地桌面应用。
- 不做服务器端。
- 不做 SSH 登录和长连接。
- 不做公网访问、手机端和 Web 管理后台。
- 画布、临时图片、分类图片和分类关系都需要在本地持久保留。

SSH 长连接属于后续服务器版能力，不应阻塞本地版的核心交互设计。

## 3. 核心交互

### 3.1 悬浮窗快速拖入

用户把图片文件直接拖到悬浮窗，图片自动进入当前画布，不要求立即选择分类。

### 3.2 展开面板粘贴

点击悬浮窗后展开小面板。用户在图片来源处复制内容，在工具内使用 `Ctrl+V`，图片进入当前画布。

### 3.3 画布操作

- 创建多个画布，如“画布 1”“画布 2”。
- 在画布之间切换。
- 画布尺寸不限，采用无限画布交互。
- 在画布空白处拖动以平移视图。
- 拖动图片主体以调整图片在画布中的位置。
- 向当前画布增加图片。
- 从当前画布移除单张图片。
- 关闭软件和重启软件后，画布及其内容继续保留。

## 4. 图片状态和存储规则

### 4.1 未分类图片

- 拖入或粘贴后先作为当前画布的临时资源保存。
- 不自动进入分类图片库。
- 关闭软件后不删除。
- 重启软件后继续存在。
- 单张从画布移除时，删除这张临时资源。
- 删除画布时，删除该画布中剩余的未分类图片。

### 4.2 已分类图片

- 点击图片后打开快速分类窗口。
- 可选择一个分类进行归档。
- 支持多选图片后批量归入同一分类。
- 分类后图片进入本地持久化图片库。
- 分类后的图片默认仍保留在当前画布上。
- 从画布移除时，只移除画布引用，图片库中的原文件保留。
- 删除画布时，已分类图片不删除。

## 5. 快速分类

- 点击画布图片打开分类窗口。
- 分类窗口显示已有分类。
- 支持新建分类。
- 单张图片支持快速分类。
- 多张选中图片支持批量分类。

## 6. 图片取出

- 图片支持直接拖出到文件管理器或其他应用。
- 图片卡片上的拖出按钮用于启动系统文件拖拽，避免和画布内定位操作冲突。
- “复制到剪贴板”指复制图片文件，而不是只复制像素内容。
- 复制后可以在支持文件粘贴的应用中使用。

## 7. 画布删除

删除画布前需要二次确认。

删除结果：

| 对象 | 结果 |
| --- | --- |
| 未分类图片 | 删除 |
| 已分类图片 | 保留 |
| 已分类图片在该画布上的引用和布局 | 删除 |
| 画布本身 | 删除 |

## 8. 第一阶段验收标准

- 图片拖到悬浮窗后自动进入当前画布。
- 展开面板后可以用 `Ctrl+V` 粘贴图片。
- 拖入和粘贴不会强制弹出分类窗口。
- 可以创建、切换和删除多个画布。
- 画布和未分类图片在软件重启后仍然存在。
- 支持单张图片从画布移除。
- 支持点击图片快速分类。
- 支持多选图片批量分类。
- 删除画布时只清理未分类图片。
- 已分类图片在删除画布或从画布移除后仍保留在本地图片库。
- 图片可以作为文件拖出或复制到剪贴板。

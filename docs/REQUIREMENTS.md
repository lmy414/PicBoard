# PicBoard：本期需求

## 产品定位

PicBoard 是一个剪贴板增强工具。它在后台记录复制过的内容（文本、富文本、链接、图片），用户把想留下的内容拖到无限画布上整理，在画布中双击打开编辑或查看，再复制出去使用。

本地优先：没有账号，没有服务器，不联网。

## 本期范围

- 只做 Windows 本地桌面应用，不做服务器、账号和云同步。
- 应用由主窗口和系统托盘组成：关闭主窗口默认收纳到托盘，后台记录继续。
- 覆盖剪贴板收集、画布整理、整页查看与编辑、富文本插图、连线、分类库、历史保留和插件接口。
- 画布有背景图案、网格吸附和不重叠的自动布局。
- 画布、内容、分类关系和设置都保存在本机。
- 界面是中文。

## 收集

- 记录开启时，后台监听 Windows 剪贴板，文本、富文本、链接和图片进入右侧“剪贴板历史”。
- 记录可以暂停。暂停后不再新增记录，已有历史保留。历史面板顶部和设置页各有一个开关。
- 连续复制相同内容只记一次：新内容与最新一条记录完全相同时复用该记录，并更新它的使用时间。
- 遵守 Windows 剪贴板排除标记。任一标记存在就不记录：
  - `ExcludeClipboardContentFromMonitorProcessing`
  - `CanIncludeInClipboardHistory = 0`
  - `Clipboard Viewer Ignore`
- PicBoard 自己复制出去的内容带 `PicBoard.ContentIds` 标记，不会被重复记录。
- 面板内 `Ctrl+V` 读取系统剪贴板，把内容放到当前画布。

## 内容类型与识别

每条剪贴板内容只归为一种类型。优先级从高到低：

1. 整段文本（去掉首尾空白）是一个绝对 http(s) 网址：链接。
2. HTML 片段包含可见文字：富文本，同时保留纯文本和 HTML。
3. 剪贴板带位图：图片，保存为文件。
4. 其他非空文字：文本。

链接最长 2048 个字符，必须是 http 或 https，并且带主机名。不合法时按下一优先级处理。

## 节点、连线与子画布

- 每条内容是画布上的一个节点。同一条内容可以有多个节点，分布在不同的画布上。
- 节点大小由内容类型决定，本期不能手动调整。
- 子画布是父画布上的节点组卡片，可以无限嵌套。
- 左侧树展示全部画布。在树中拖动可以调整父子层级和顺序；拖动时底部出现“拖到此处设为根画布”，放上去变回根画布。
- 拖动节点或子画布卡片时，元素直接跟随指针，自由移动时与指针完全同步；开启网格对齐后按网格步进。按住 `Alt` 临时反转当前模式。按下时轻微抬起，松开后缓动落位。
- 节点和子画布卡片之间保留 16 px 间距，不会重叠。放置到已占用的位置时，内容滑到最近的空位。
- 文本内容变高时，被它挡住的内容向下让位。
- 把节点拖到子画布卡片上，节点移入该子画布。
- 从节点边缘的连接点拖到另一个节点建立连线。连线带箭头，只表示关联，不传递数据。
- 选中连线按 `Delete` 删除。删除节点时，与它相连的连线一起删除。
- 一端被收进子画布后，父画布上的连线画到对应的子画布卡片上；解组后连线回到原节点。

## 画布外观与网格

- 图案：网点、网格线、无。
- 背景颜色：预设暖白、纯白、米色、雾蓝、深灰，也可以自选颜色。
- 图案颜色可调，图案浓度 0%–60%。
- 网格间距：16、24、32。
- 网格对齐：默认关闭，拖动时节点与指针完全同步；开启后拖动和放置按网格吸附。拖动时按住 `Alt` 临时反转当前模式。
- 默认：暖白背景、网点图案、间距 24、网格对齐关闭。
- 图案随画布平移和缩放一起移动。
- 图案、背景和浓度只保存在本机，不写进内容数据；间距和对齐保存在桌面设置里。

## 打开与编辑

- 单击选中节点，`Shift` 单击增选或取消选择；双击或按 `Enter` 打开整页。
- 文本、富文本：所见即所得编辑器。
  - 输入 `/` 插入标题 1–3、无序列表、有序列表、待办列表、引用、代码块、分割线、3×3 表格。
  - 选中文字出现格式工具条：加粗、斜体、下划线、删除线、行内代码、链接。
  - 图片可以插入正文：粘贴图片文件、粘贴带图片的 HTML，或输入 `/` 选择“图片”。
  - 图片保存在 `content/<id>/assets/`，远程图片不会加载；纯文本里图片显示为 `[图片]`。
  - 停止输入 600ms 后自动保存，状态显示“保存中…”“已保存”或“保存失败”。
- 图片：整页大图查看。滚轮以指针位置为中心缩放，拖动平移，双击在适应窗口和 100% 之间切换。
- 链接：显示域名和完整地址，可以编辑地址、复制链接，或在浏览器打开。只允许 http/https 地址，不联网获取标题或预览。
- 子画布：进入该子画布。
- 整页顶部显示类型、分类和创建/编辑时间，文本页还有保存状态，并列出这条内容出现在哪几个画布。
- 点页面左上角“← 返回”、顶部栏的来源面包屑或按 `Esc` 返回；从分类库打开的整页返回分类库。有弹窗或菜单时，`Esc` 先关闭它们，再关闭整页。

## 多处引用与删除

- 同一条内容可以放进多个画布。在任意位置编辑，所有位置同步。
- 从画布移除（`Delete` 或“从画布移除”）：只去掉当前画布上的节点，内容回到剪贴板历史。
- 删除内容：从所有画布移除，并删除这条内容。确认框会写明它出现在几个画布。图片文件移到 Windows 回收站，正文里插入的图片随内容目录一起删除。
- 删除画布：连同全部子画布一起删除。其中的内容回到剪贴板历史，不删除内容。

## 复制出去

`Ctrl+C` 或“复制”按原格式写回系统剪贴板：

- 文本：纯文本。
- 富文本：纯文本，另写一份 HTML。正文里的图片以内嵌 data URL 写入 HTML（单张 8 MB、合计 24 MB 以内）。
- 链接：网址文本。
- 图片：位图数据（PNG、CF_DIBV5、CF_DIB、CF_BITMAP）和文件（`CF_HDROP`）。复制多张图片时写文件列表。

复制出去的内容带 PicBoard 标记，不会再次进入历史。

## 分类库

- 所有类型都能分类。分类只是标记，不移动文件。
- 分类库列出全部内容，可以按类型（文本、富文本、链接、图片）、分类（含“未分类”）和创建时间（今天、7 天内、30 天内）筛选。
- 搜索按内容文字、链接和文件名匹配。
- 卡片显示类型、分类、创建时间和出现在几个画布；富文本卡片用正文第一张图作为封面。
- 双击卡片打开整页。支持 `Shift` 多选和 `Ctrl+C` 复制。

## 历史保留

- 默认 30 天，可选 7 天、30 天、90 天、1 年或永久保留。
- 只清理既没有放到任何画布、也没有分类的内容，按最后使用时间计算。
- 清理在启动时、修改保留时间后，以及之后每 6 小时执行一次。
- 自动清理直接删除对应文件，不进回收站。
- 时间戳无法解析的内容保留，不删除。

## 主窗口与托盘

主窗口是一个普通桌面窗口：在任务栏显示、可自由调整大小（最小 720×480）、不置顶。默认大小 1000×700，大小和位置会记住（最大化时不记录）。双击标题栏或点击“□”最大化或还原，“−”最小化，“×”按设置处理。

- 关闭行为：默认收纳到托盘，进程和后台记录继续；设置里可以改为退出程序。
- 侧栏在窗口宽度 ≥1100 px 时靠边，否则收成细栏、点开为浮层。
- 剪贴板历史在画布足够宽时靠边，否则为浮层。
- 窗口宽度 ≤900 px 时，设置、历史和画布工具按钮收进顶部栏的“⋯”菜单。
- 画布宽度小于 560 px 时小地图隐藏。

托盘图标：

- 左键打开剪贴板面板（约 420×600，靠近托盘图标，失焦自动收起）。
- 右键菜单：打开 PicBoard / 退出。

剪贴板面板：

- 顶部：记录中/已暂停（点击切换）、打开主窗口、设置。
- 类型标签 全部/文本/图片/链接 带数量，文本标签同时覆盖富文本；搜索框；显示“今天 N 条 · 共 M 条”。
- 列表按时间倒序，滑到底部继续加载。
- 单击条目复制；`Space` 或条目上的箭头展开预览；双击在主窗口打开；“⋯”或右键：复制、预览、在主窗口打开、分类（可新建）、删除内容（行内确认）。
- 键盘：`↑`/`↓` 选择，`Enter` 复制，`Space` 预览，`Delete` 删除确认，`Esc` 逐层关闭，直接打字聚焦搜索。
- 底部：打开 PicBoard / 退出。

开机自启动的启动带 `--autostart` 参数：静默进入托盘，不弹主窗口。

## 外观主题

- 设置页第一节“外观”提供两个主题：简洁（默认，平面浅色界面，细边框与轻阴影）和新拟物（柔和的凹凸光影，控件像从底色中浮出）。
- 选择保存在渲染器 localStorage 的 `quick-image-board.theme`，主窗口和托盘面板共用，重启后保持。
- 切换立即生效，有一次短交叉淡入；系统“减少动态效果”开启时不播放过渡。
- 画布背景没有自定义过时跟随主题，自定义过之后保持自定义。

## 处理节点插件（仅接口）

- 首期只提供插件接口，不提供内置处理节点，也没有执行引擎和画布上的运行入口。
- 插件放在数据目录的 `plugins/<文件夹>/` 下，包含 `manifest.json` 和入口脚本（默认 `main.js`）。
- 设置页列出插件目录、加载状态，以及每个插件声明的处理节点、输入输出和端口类型。
- 接口定义、清单字段、端口兼容规则和运行契约见 [PLUGIN-API.md](PLUGIN-API.md)。
- 插件在独立 Worker 中运行，没有 DOM 和 Tauri IPC，网络接口在加载前被移除。这不是针对恶意代码的强沙箱。

## 本期不做

- 从其他应用拖入文件或文字。
- 把内容拖出到其他应用。
- 在画布空白处新建节点。
- 调整节点大小。
- 画布级的撤销和重做。
- 图片编辑（裁剪、标注等）。
- 连线文字标签。
- 全局快捷键调出历史。
- 直接粘贴到其他软件。
- 文件和软件私有格式等其他内容类型。
- 内置处理节点、处理节点的执行引擎和画布上的数据线。

## 验收标准

- 记录开启时，复制一段文字，剪贴板历史出现一条记录。
- 暂停记录后复制，历史不再新增；恢复后继续记录。
- 连续两次复制相同文字，历史里只有一条，且时间更新为第二次复制的时间。
- 来源应用带排除标记的内容不进入历史。
- 复制 PicBoard 里的内容后，历史不新增重复记录。
- 整段文本是一个 http(s) 网址时识别为链接；带可见文字的 HTML 识别为富文本；图片识别为图片；其余非空文字识别为文本。
- 双击历史条目或画布节点进入整页，`Esc` 或“返回”回到原位置。
- 默认不开启网格对齐，拖动时节点与指针完全同步；开启后拖动按网格步进，按住 `Alt` 拖动反转当前模式。设置里能改图案、背景颜色、图案浓度和网格间距，图案随平移缩放移动。
- 设置 → 外观可切换简洁和新拟物；主窗口和托盘面板同时换主题，重启后保持；未自定义画布背景时背景跟随主题。
- 节点和子画布卡片不重叠（间距 16 px）；放到已占用的位置会滑到最近空位；文本变高后下方内容下移。
- 用 v1 数据启动一次后，每个画布的内容不重叠。
- 文本页输入 `/` 出现插入菜单，包含标题 1–3、无序列表、有序列表、待办列表、引用、代码块、分割线、表格和图片；停止输入后状态变为“已保存”，重新打开内容仍在。
- 文本页粘贴图片或输入 `/` 选“图片”后，图片保存在 `content/<id>/assets/`，重新打开仍在；远程图片不显示也不加载。
- 富文本正文有图时，画布卡片、历史列表和分类库显示第一张图作为封面；纯文本里显示 `[图片]`。
- 图片页滚轮缩放，双击在适应窗口和 100% 之间切换。
- 链接页只有 http/https 地址可以“在浏览器打开”，且不会抓取网页内容。
- 从节点边缘拖到另一个节点出现带箭头连线；选中连线按 `Delete` 删除；删除节点后相关连线消失。
- 一端收进子画布后，连线画到子画布卡片上；解组后连线回到原节点。
- 同一条内容放进两个画布，在整页编辑后两个画布同时更新。
- 在画布上按 `Delete` 只移除当前画布的节点，内容仍在剪贴板历史。
- 删除内容前的确认框显示它出现在几个画布；确认后所有画布移除，图片进入 Windows 回收站。
- 删除画布及其子画布后，内容仍在剪贴板历史。
- `Ctrl+C` 复制文本写入纯文本；复制富文本同时写入纯文本和 HTML；复制链接写入网址；复制图片写入位图和文件。
- 复制富文本时，正文图片以内嵌 data URL 写入 HTML。
- 整页左上角“← 返回”和顶部栏来源面包屑都能返回；有弹窗或菜单时，`Esc` 先关闭它们，再关闭整页。
- 拖动左侧树节点时才出现“拖到此处设为根画布”，放上去后画布变回根画布。
- 菜单、对话框、提示、整页、历史条目、分类库卡片、节点和连线出现和消失时有缓动动画；系统开启“减少动态效果”后关闭。
- 点击“−”最小化；“□”或双击标题栏最大化；窗口最小 720×480，重启后大小和位置保留。
- 点击“×”默认收纳到托盘，进程和后台记录继续；在设置里改为退出程序后，点击“×”结束进程。
- 窗口宽度变化时，侧栏、历史、顶部栏按钮和小地图分别按 1100 px、画布宽度、900 px、560 px 的阈值切换。
- 左键托盘图标打开面板，右键菜单是 打开 PicBoard / 退出；面板失焦自动收起。
- 面板里单击复制，`Space` 预览，双击在主窗口打开，菜单里能分类和删除；`↑`/`↓`/`Enter`/`Space`/`Delete`/`Esc` 按主窗口与托盘一节的规则工作。
- 开机自启动后应用静默进入托盘。
- 分类不移动文件；分类库能按类型、分类、创建时间筛选，并支持关键词搜索。
- 把保留时间改为 7 天后会立即清理一次：超过 7 天且未放到画布、未分类的内容消失，对应文件被删除；已放到画布或已分类的内容保留。
- 设置页插件区能列出插件目录里的插件和它们的处理器；画布上没有运行处理节点的入口。
- 关闭并重新启动后，画布、节点、连线、分类关系和设置都保留。

# PicBoard v0.3.0

发布日期：2026-11-03

本次更新整理画布与图片工具，新增无损橡皮擦、设置分栏和黑夜主题，并修复窗口拖动、调整大小及侧栏展开收起的交互。

## 画布与内容

- 底部居中的悬浮工具胶囊提供添加、选择、抓手、富文本、链接、导入图片、剪贴板历史和快捷键帮助。按钮有文字提示，窄窗口下会调整布局。
- 缩放与网格工具移到左下角，默认只显示缩放比例；点击展开网格对齐、缩小、放大和定位全部，再次点击即可折叠。
- 移除右上角重复的工作区导航，画布与分类库通过左侧切换；原顶栏位置和窗口操作按钮保留。
- 新建文字统一使用富文本编辑器。已有纯文本继续兼容，编辑后统一保存为富文本；历史、分类库和托盘使用统一的富文本筛选入口。
- 导入图片或保存编辑副本后，内容会放到当前来源画布，并选中、定位；保存副本保留原图。

## 图片查看与编辑

- 图片查看的缩放、适应窗口和原始大小控件改为底部悬浮胶囊。
- 编辑工具分为绘制、撤销与变换、属性、保存与导出几组胶囊。工具区根据实际高度为图片留出空间，支持小窗口换行。
- 新增橡皮擦，可擦除本次编辑中的笔画、箭头、方框、文字及马赛克，恢复底图及透明度；显示擦除范围和实时预览。
- 底图与编辑层分离，裁剪、旋转和翻转后继续绘制或擦除时使用正确坐标，支持撤销、重做。
- 保留 PNG、JPEG、WebP 导出、保存独立副本和放弃修改确认。保存副本时等待画布放置完成，再返回来源画布；处理过程中阻止重复关闭或导航。
- 优化原图加载优先级、缓存命中与显示时机，将原图读取和缩略图处理分到独立队列；改善外部图片和启动请求的排队与交付。

## 窗口与侧栏

- 保留整条标题栏、最小化、最大化或还原、关闭按钮及边框调整大小。
- 修复标题栏拖动与系统窗口拖动的衔接，支持双击最大化或还原、从最大化状态拖动还原，并强化八方向缩放和多显示器边界处理。
- 手动再次启动 PicBoard.exe（不带图片参数）会恢复已经运行的主窗口；`--autostart` 继续静默进入托盘。
- 侧栏悬停临时展开，点击固定或收起。临时展开不推动画布，固定时画布平滑让位；从按钮移入面板有短暂缓冲。
- 搜索、键盘焦点、树节点菜单、重命名对话框和拖动画布层级时保持展开，避免操作中途收起。
- 移除普通侧栏重复的工作区标题行，临时展开时的固定、收起按钮并入搜索行。
- 修复首次载入时隐藏侧栏的键盘焦点隔离，以及减少动态效果模式下 Ctrl+K 的聚焦时序；Esc 按层级关闭并恢复合理焦点。

## 设置与主题

- 设置改为左侧项目、右侧对应页面的分栏布局，包含画布、剪贴板、存储目录、窗口与启动、默认图片打开器、分类管理、插件和外观。
- 左侧支持搜索设置项目；进入设置时保持稳定分栏，返回画布后恢复原来的侧栏固定或收起偏好。
- 新增浅色、黑夜和跟随系统三种主题，记住本机偏好，并覆盖主窗口、内容页、设置和托盘面板。
- 在设置的默认图片打开器页面，可注册 PicBoard 的 PNG、JPG、JPEG、WebP、BMP、GIF 打开能力，并进入 Windows 默认应用页面选择关联；已有注册可以直接管理。

## 图片打开性能的实测范围

在报告列出的本机环境中，对已有 1080p PNG、4K PNG、24 MP JPEG 各执行三轮冷开及再次打开，完整解码与可见首帧均小于 1,000 ms；最慢可见首帧为 603.8 ms。

这衡量的是运行中的画板双击已有图片，不包含系统文件选择、外部图片首次入库以及应用和 WebView 冷启动，也不代表任意硬件、图片体积均可达到相同耗时。详细环境、样本、对照结果和复现方法见 [图片打开性能实测](https://github.com/lmy414/PicBoard/blob/v0.3.0/docs/IMAGE-OPEN-PERFORMANCE.md)。

## Windows x64 便携包

- 程序包：`PicBoard-v0.3.0-windows-x64.zip`
- 校验清单：`PicBoard-v0.3.0-windows-x64.manifest.json`
- 发布包 SHA-256：见发布资产中的 `PicBoard-v0.3.0-SHA256SUMS.txt` 和校验清单。
- 使用系统 Microsoft Edge WebView2 Evergreen Runtime，不随包提供固定运行时。
- 便携版未签名，无安装器或自动更新器。解压整个 ZIP 后运行 `PicBoard.exe`。
- 设置默认图片应用前，请把便携目录放在稳定位置；移动目录后需要重新注册。

## 数据兼容

从 v0.2.0 升级继续使用 schema v2 和原有数据目录，无需搬运已有内容。默认数据目录保持 `%APPDATA%\quick-image-board\quick-image-board`，原有 Tauri identifier 和本地兼容标识保持不变。

更早的 v0.1.2 数据首次打开时会升级为 schema v2，旧状态文件保留为 `state.v1-backup.json`。v0.1.2 不能读取升级后的状态，升级前应保留数据目录备份。设置中的存储目录偏好不会自动迁移现有内容。

## 回归覆盖

本轮增加或扩展了真实 Edge 图像像素、透明度、导出、保存回画布、设置分栏、主题、侧栏焦点与悬停、窄窗口布局及图片打开性能回归，同时补充组件、Node、Rust 和原生窗口交互验证。

原生拖动、系统调整大小和托盘激活使用隔离数据目录进行验证，不通过改动正式用户图库完成发布验收。
